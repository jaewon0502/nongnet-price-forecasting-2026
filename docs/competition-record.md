# 대회 기록과 출처

대회 사이트가 닫혀도 프로젝트의 배경을 알 수 있도록, 2026년 11월 9일에 당시 확인한 내용을 정리했고, 11월 21일에 [최종 결과](#final)를 추가했습니다. 공식 원문의 사본이나 운영진이 발급한 성적 증명서는 아닙니다.

| 항목 | 내용 |

## 참가 규모

2026년 10월 23일 [머니투데이](https://www.mt.co.kr/policy/2026/10/23/2026102309341731178)와 [월간친환경](https://www.digitalorganic.net/news/articleView.html?idxno=48409)은 aT 발표를 인용해 **394팀·566명이 참가했고, 예선 심사로 본선 15팀을 뽑았다**고 보도했습니다. 팀 수 기준으로 약 26:1의 경쟁이었습니다.

이 프로젝트의 본선 진출은 같은 날 게시된 [본선 진출팀 선정 결과](https://hackathon.imaginationgroup.co.kr/nongnet/notices?id=notice-finalists-20261023)로 확인했습니다. 두 기사는 대회 규모를 다룰 뿐, 이 프로젝트의 순위나 수상을 보도한 것은 아닙니다.

## 리더보드 기록

2026년 11월 8일 23:46 KST에 본선 공개 리더보드에서 확인한 값입니다.

| 항목 | 표시값 |
|---|---:|
| 잠정 순위 | **1위** |
| 10일 MAPE | 8.7643% |
| 2순 뒤 MAPE | 8.8317% |
| 3순 뒤 MAPE | 8.3843% |
| 종합 MAPE | **8.7174%** |

이 순위는 재현 검증과 이의 처리 전의 기록입니다. 최종 순위와 수상 결과는 아래 [최종 결과](#final)에 적었습니다.

같은 예측을 로컬에서 다시 계산한 종합 MAPE는 8.7174%로 화면 값과 같았습니다. 그 전까지 리더보드에 올라 있던 이 프로젝트의 기록은 9.9670%였습니다. 2순·3순 뒤 설정을 바꾼 중간 조합(8.9058%)은 리더보드에 올리지 않았습니다.

## 최종 결과

2026년 11월 21일에 추가했습니다.

| 항목 | 내용 |
|---|---|
| 최종평가 | 2026년 11월 20일, 본선 리더보드 상위 5팀의 발표평가 (발표 15분, 질의응답 5분) |
| 최종 순위 | **1위** |
| 수상 | **대상 (농림축산식품부 장관상)** |
| 시상 구성 | 대상 1팀(농림축산식품부 장관상), 우수상 4팀(aT 사장상) |

순위와 수상은 2026년 11월 21일 기준으로 확정된 내용을 본인이 확인해 적었습니다. 평가 방식은 운영진이 발표 대상 팀에 안내한 최종평가 계획을, 시상 구성은 대회 사이트 첫 화면의 시상 안내를 따랐습니다. 대회 사이트 첫 화면은 [최종 수상 결과 공지](https://hackathon.imaginationgroup.co.kr/nongnet/notices?id=notice-final-awards-20261120)로 연결되지만, 공지 본문은 로그인해야 볼 수 있어 이 문서에 내용을 옮기지 않았습니다.

최종평가 계획에 따르면 순위는 발표 점수로만 정하고, 리더보드 순위는 발표 대상 팀을 고르고 동점을 가리는 데만 씁니다. 수상과 별개로, 리더보드 점수 8.7174%는 모델을 쓴 9칸의 설정을 2025년 점수를 보고 고른 결과라서 처음 보는 데이터에서의 성능으로 읽을 수 없습니다. 자세한 내용은 [README의 한계](../README.md#limits)에 적었습니다.

<a id="evaluation"></a>
## 평가 방식

MAPE는 실제 가격 대비 오차의 절대 비율을 평균한 값이며, 낮을수록 좋습니다. 실제 가격이 없는 날(휴장일 등)은 계산에서 빠집니다.

```
품목 MAPE(%) = mean(|예측 − 실제| / 실제) × 100
기간 MAPE   = Σ(품목 MAPE × 품목 가중치) / 8.4
종합 MAPE   = 10일 × 0.70 + 2순 뒤 × 0.15 + 3순 뒤 × 0.15
```

| 품목 | 가중치 | 가격 단위 |
|---|---:|---|
| 배추 | 2 | 원/10kg |
| 무 | 2 | 원/20kg |
| 양파 | 2 | 원/kg |
| 깐마늘 | 1.2 | 원/kg |
| 건고추 | 1.2 | 원/600g |

10일 예측의 배추·무·양파가 종합 점수에서 차지하는 비중은 `0.70 × (2 + 2 + 2) / 8.4 = 0.50`입니다.

<a id="selection"></a>
## 모델 선택에 관한 규정

2026년 11월 3일자 「본선 제출·가격 기준·검증 통합 안내」(11월 8일 열람)에서 이 프로젝트와 관련된 내용은 다음과 같습니다.

- 품목마다 다른 모델이나 앙상블을 쓰는 것은 허용됩니다.
- 모델 학습과 방법·설정 선택에는 2020\~2024년 자료만 씁니다. 2025년 평가 정답이나 채점 결과에 맞춰 방법·설정·혼합 비율을 고르거나 고치는 것은 금지됩니다.
- 이미 제출한 후보들의 리더보드 점수를 비교해 가장 좋은 원본을 검증 대상으로 정하는 것은 허용됩니다.
- 검증에서는 원본 재현, 재학습, 데이터 시점, 선택 과정을 함께 봅니다. 프로그램이 돌아가고 점수가 같다는 것만으로 통과가 정해지지 않습니다.

이 프로젝트는 모델을 쓴 9칸(배추·무·양파의 10일·2순 뒤·3순 뒤)의 설정을 2025년 채점 결과를 본 뒤 골랐기 때문에 두 번째 항목에 걸릴 수 있습니다. LightGBM 학습에는 2024년까지의 자료만 썼지만, 학습에 쓴 자료와 설정을 고른 근거는 별개입니다. README에서 리더보드 점수와 일반화 성능을 나눠 설명한 이유입니다.
