## 참가 규모와 본선 진출

2026년 10월 23일 [머니투데이의 대회 보도](https://www.mt.co.kr/policy/2026/10/23/2026102309341731178)와 [월간친환경의 대회 보도](https://www.digitalorganic.net/news/articleView.html?idxno=48409)는 aT의 발표를 인용해 **394개 팀·566명이 참가했고, 예선 심사를 거쳐 본선 진출 15팀을 선정했다**고 전했습니다. 두 기사는 대회 전체의 참가 규모와 선발 과정을 다룹니다.

| 항목 | 확인한 수치 | 근거 |
|---|---:|---|
| 참가팀 | 394팀 | 두 언론 보도에 기재된 참가팀 수 |
| 참가인원 | 566명 | 두 언론 보도에 기재된 참가인원 |
| 본선 진출팀 | 15팀 | 언론 보도 및 2026-10-23 공식 선정 결과 |
| 팀 기준 예선 경쟁률 | 약 26.3:1 | 보도된 참가팀 수를 기준으로 직접 계산 |
| 본선 진출 비율 | 약 3.8% | 보도된 참가팀 수를 기준으로 직접 계산 |

`예선 경쟁률 = 394팀 ÷ 15팀 = 26.2666…:1 ≈ 26.3:1`

`본선 진출 비율 = 15팀 ÷ 394팀 × 100 = 3.8071…% ≈ 3.8%`

경쟁률은 참가인원 566명이 아닌 참가팀 394팀을 기준으로 계산했습니다. 위 비율은 기사 수치로 계산한 예선 선발 규모이며, 운영진이 별도로 발표한 경쟁률이나 본선 모델 성능의 백분위는 아닙니다.

본 프로젝트의 본선 진출은 [공식 본선 진출팀 선정 결과](https://hackathon.imaginationgroup.co.kr/nongnet/notices?id=notice-finalists-20261023)의 참가자 명단과 기존 참가 기록으로 확인했습니다. **기사의 참가 규모·선발팀 수와 아래의 잠정 리더보드 1위 기록은 서로 다른 근거입니다.** 두 기사가 본 프로젝트의 순위·최종 검증 통과·수상을 보도한 것은 아닙니다.

기사의 매체명·제목·게시 시각·확인일과 핵심 수치를 이 문서에 남겼습니다. 외부 링크가 종료돼도 참가 규모와 계산 과정을 읽을 수 있으며, 기사 원문 전체나 이미지는 재게시하지 않습니다.

## 평가 기준 요약

MAPE는 관측값이 있는 날짜에서 실제 가격에 대한 절대 상대 오차를 평균한 백분율입니다. 작을수록 오차가 낮습니다.

`품목 MAPE(%) = mean(|예측가격 − 실제가격| / 실제가격) × 100`

관측값이 없는 날짜를 0이나 보간값으로 채워 정답으로 사용하지 않습니다. 장기 목표는 해당 순의 실제 관측일 가격 평균입니다.

| 품목 | 품목 가중치 | 제출 가격 단위 |
|---|---:|---|
| 배추 | 2 | 원/10kg |
| 무 | 2 | 원/20kg |
| 양파 | 2 | 원/kg |
| 깐마늘 | 1.2 | 원/kg |
| 건고추 | 1.2 | 원/600g |

`기간별 MAPE = Σ(품목 MAPE × 품목 가중치) / 8.4`

`종합 MAPE = 10일 MAPE × 0.70 + 2순 후 MAPE × 0.15 + 3순 후 MAPE × 0.15`

이 가중치에서 단기 배추·무·양파가 종합 점수에 차지하는 비중은 `0.70 × (2 + 2 + 2) / 8.4 = 0.50`입니다. README의 개선 우선순위 설명은 이 계산을 근거로 합니다.

실제 관측값의 결측 처리와 기간별 정의는 당시 공지를 확인했고, 위 집계식은 해당 가중치를 적용한 본 프로젝트의 로컬 평가에서도 사용했습니다. 0 이하의 가격을 오류로 처리하거나 계산 중간에 표시 자릿수로 반올림하지 않는 처리는 로컬 평가 구현의 원칙입니다.

## 당시 확인한 선택·검증 기준

2026년 11월 3일자로 표시된 「본선 제출·가격 기준·검증 통합 안내」를 11월 8일에 열람했습니다. 포트폴리오의 해석에 필요한 부분은 다음과 같습니다.

- 품목별로 다른 모델을 쓰거나 앙상블을 사용하는 구성은 허용됐습니다.
- 기본 모델의 학습과 방법·설정의 개발·선택에는 2020~2024년 자료 제한이 적용됐습니다. 2025년 정답이나 채점 피드백에 맞춘 새로운 방법·설정·혼합비율 등의 개발·선택은 제한됐습니다.
- 사전에 정한 추론 절차에 따라 해당 사례에 허용된 과거 입력으로 계수·상태를 추정하는 것은 별도로 다뤄졌습니다.
- 이미 제출한 후보 중 기간별 최고 기록 원본을 정하는 절차와, 평가 결과를 이용해 새 구성을 만드는 행위는 구분됐습니다.
- 최종 판단에는 원본 추론, 실제 재학습, 데이터 시점과 선택 과정 등이 포함됐습니다. 프로그램 실행 성공이나 점수 일치만으로 전체 검증 통과가 확정되는 것은 아니었습니다.

본 프로젝트의 최종 구성 선택에는 이미 확인한 2025년 평가 결과가 사용됐습니다. 이에 관한 제한과 실제 선택 이력 사이에 검증 쟁점이 남아 있었으므로, README에서는 공개 점수와 독립 검증 성능·적격성 판정을 구분했습니다.

이 항목은 당시 안내를 이해하기 위한 요약입니다. 원문 전체나 개별 판정의 대체물이 아니며, 이후 변경된 규정·판정은 포함하지 않습니다.
